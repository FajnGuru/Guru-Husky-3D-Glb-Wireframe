# Spuštění na localhost (PowerShell)

1. Naklonuj repo:
```powershell
git clone https://github.com/FajnGuru/Guru-Husky-3D-Glb-Wireframe.git
cd Guru-Husky-3D-Glb-Wireframe
```

2. Nainstaluj závislosti a spusť:
```powershell
npm install
npm start
```

Otevře se na http://localhost:8080

Alternativně s automatickým otevřením prohlížeče:
```powershell
npm run dev
```
